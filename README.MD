# AI Recommendation System

## Project 3 - Artificial Intelligence

This project is a simple AI-based recommendation system.

The system takes the user's interests as input and compares them with the genres of different movies. It then calculates a simple similarity score and recommends movies that match the user's interests.

The main purpose of this project is to understand basic recommendation logic, pattern matching, and similarity concepts.

## Features

- Takes user interests as input
- Matches user preferences with movie genres
- Calculates a simple similarity score
- Displays recommended movies
- Shows a message when no matching movie is found

## Technologies Used

- Python
- CSV dataset
- Basic Python logic
